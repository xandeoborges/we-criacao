# we-rtvc Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up `we-rtvc`, a new independent dashboard project (repo + Vercel deploy) that is a functional clone of `we-criacao`, scoped to the RTVC and Motion núcleos of the RTVC Taskrow department.

**Architecture:** Copy the existing `we-criacao` React 19 + Vite + TS codebase verbatim into a new sibling directory/repo. The only business-logic change is the núcleo/department filter in `buildNucleoDirectory()` (`src/lib/constants.ts`): target `FunctionGroupName === 'RTVC'` and allowlist `ApprovalGroup ∈ {'RTVC', 'Motion'}` instead of the we-criacao exclude-list approach. Every page, hook, and the workload/capacity calculation are already agnostic of the specific department and need no changes. Branding changes are limited to text (page title, package name, CLAUDE.md).

**Tech Stack:** React 19, TypeScript, Vite 8, Tailwind CSS, TanStack React Query, Recharts, bun (runtime, test runner, package manager), oxlint, Vercel serverless functions.
